🎥 OBS & phát live

  1. Mở OBS → Tools → WebSocket Server Settings → bật Enable WebSocket server (cổng 4455). Có mật khẩu thì nhập bên dưới.
  2. Bấm Thiết lập cảnh OBS: khung dọc 1080×1920, cảnh “Cậu Cả Live” chạy game, âm thanh game vào OBS.
  3. Trong OBS → Settings → Stream dán Server URL và Stream Key lấy từ TikTok LIVE (một lần).
  4. Bấm Bắt đầu phát.
